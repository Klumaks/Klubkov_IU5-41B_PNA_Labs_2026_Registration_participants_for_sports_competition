# Лабораторная работа 1
Задание: Создание калькулятора. Верстка на HTML, CSS. Копировать 3-5 основных цветов кодами с сайта по вашей теме (хедер, фон, карточки, кнопки, hover) и еще 2-3 свойства (padding и тд)
Порядок показа: объяснить все стили и теги, которые потребовалось добавить для повторения стилистики выбранного сайта (коды цветов с сайта через Inspect и в вашем CSS, hover и тд)
Контрольные вопросы: основные составляющие web, опишите URI, напишите HTML для страницы из заголовка и абзаца текста, отличительные черты протокола HTTP
